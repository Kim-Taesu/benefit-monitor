# AI 품질·신뢰도 검증 전환 설계 — 2026-11-09

## 배경

2026-11-09 점검 결과, AI 호출은 매일 나가지만 결과가 사이트에 닿지 않았다.

- AI의 역할이 "새 후보 사실 추출 + 엄격한 자동 공개"뿐이었다. 사람 승인 항목은 AI가 건드리지 않았다(이마트24 KT GOLD 오류를 사람이 발견).
- AI 실행이 무료 수집을 처음부터 다시 해서 HTTP 상한 100회 중 약 75회를 썼다. 조사 후보 11건이 본문을 읽지 못했다.
- 자동 공개 기준: 연도 없는 "11월 30일까지" 한 줄이면 보류, 게시일은 항상 비어 있어 상시 혜택은 통과 불가.
- 06시 이전 실행 금지 조건 때문에 수집 완료 연동 실행이 늘 `not_due`로 끝났다.

사용자 요구: "데이터 수집은 파이썬으로 하고 수집된 데이터에 대해서 품질 강화 신뢰도 체크를 ai agent가 해야" 한다. 승인: "A, B, C, D 개선해."

## 목표

파이썬이 수집한다. AI는 수집된 데이터를 공식 원문과 대조해 신뢰도를 판정한다. 판정은 코드가 다시 확인한 것만 효력을 갖는다.

## 변경

### 수집 결과 재사용 (A·B의 전제)

- 무료 브리핑 수집이 끝나면 수집 결과(후보·자치구 현황·성공/실패 출처)를 `cache/collection_snapshot.json`에 남긴다. 기존 AI 수신자 공개키로 age 암호화해 `briefing-data/ai-collection.age`로 올린다. 평문은 공개하지 않는다.
- AI 실행은 이 스냅샷이 오늘(KST) 것이면 목록 수집을 다시 하지 않고 그대로 쓴다. 공식 목록 요청이 하루 한 번으로 줄고, AI 실행의 HTTP 100회는 본문 확인에 쓴다. 스냅샷이 없거나 오래됐으면 기존처럼 다시 수집한다.

### A. 공개 항목 대조 검증 (kind `verify`)

- 대상: 사람 승인 공개 항목. 마지막 AI 검증이 오래된 순서로 돌린다.
- 입력: 저장된 주장(요약·조건·기간·요금)과 공식 원문 1건.
- 출력: 주장마다 `supported`·`contradicted`·`not_found`와 원문 인용, 원문 기준 값.
- 코드 확인: 인용문이 원문 본문에 그대로 있어야 한다. 아니면 그 판정은 버린다(`unverifiable`).
- `contradicted`가 확인되면 운영 상태에 `hold_reason='ai_contradicted'` 보류를 건다. 기존 보류처럼 사람이 다시 검증해 `verified_at`이 보류 시각보다 새로워질 때까지 공개 목록에서 빠지고 재검증 대기에 오른다. AI는 내용을 고치지 않는다.

### B. 검토 대기 분류 (같은 kind `verify`)

- 대상: 검토 대기 후보.
- 출력: `ongoing`·`upcoming`·`ended`·`not_benefit`·`unclear`와 원문 인용.
- 코드 확인:
  - `ended`: 인용문에 4자리 연도가 적힌 종료일이 오늘보다 앞서거나, 종료 표현(종료·마감되었 등)이 있어야 한다.
  - `not_benefit`: 인용문이 원문에 있어야 한다.
- 확인된 `ended`·`not_benefit`은 대기열에서 뺀다(`ai_dismissed`). 원문 본문이 바뀌면 다시 분류한다. 공개·검증·종료 표시는 하지 않는다.
- `ongoing`·`upcoming`은 대기열 앞쪽으로 정렬해 사람이 먼저 보게 한다.

### C. 자동 공개 기준 정비

- 연도 없는 마감 문구라도 같은 문서에 연도와 함께 적힌 같은 월·일이 현재 이후면 보류 사유로 보지 않는다.
- 공식 페이지 머리의 게시일(서울 미디어허브 `발행일`)을 코드가 읽어 문서 `published_at`에 넣는다. 상시 혜택의 최근 게시 조건은 모델 값 대신 이 값으로도 충족된다.
- 사람이 이미 승인한 항목은 조사(research) 대상에서 빼고 A가 맡는다.

### D. 실행 시점

- 06시 이전 실행 금지 조건을 없앤다. 이미 있는 "오늘 무료 수집 완료 확인"과 10시 대체 수집 실행이 시점을 정한다.

## 한도

- 하루 유료 요청: 검증 40, 조사 20, 주제 1, 문법 시험 3(새 검증 스키마 포함).
- 검증 1건은 약 $0.001~0.002로 추정한다. 하루 최대 약 $0.1, 월 상한 $15 안이다. 월 상한은 그대로 프로그램 원장이 강제한다.
- 실행당 HTTP 100회, 모델 Haiku 5.5 고정, 무료 인프라, 출처·robots 규칙은 그대로다.

## 반목표

- AI 판정만으로 공개 항목 내용을 고치거나 새로 공개하는 것(A는 보류만 한다).
- 원문에 없는 인용으로 보류·제외하는 것.
- 끝난 행사가 진행 중처럼 보이는 것(기존 최우선 금지 유지).
