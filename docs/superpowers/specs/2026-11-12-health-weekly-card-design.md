# 이번 주 보건소 추천 카드 — 설계 (2026-11-12)

## 의도

사용자 요청(2026-11-12): 보건소 상시 사업 페이지(예: 강서 대사증후군 ht020103)를 가져와 AI가 핵심만 뽑고,
"이번 주 보건소 추천" 카드에 "20세~69세 관내 구민은 대사증후군 조기 발견을 위한 무료 검진을 받을 수 있습니다"
같은 요약이 보이게 하고 싶다. 표시 범위는 "서울 전체와 각 지역구들의 요약을 짧게", 서울 전체 줄은 "묶는 형태"
(같은 사업을 하는 구를 세어 묶음)로 골랐다.

1·2단계(수집, AI 요약)는 이미 있다: `health_programs` 62곳 확인(PR #43), 페이지별 AI 문장
`health_notes`(PR #44, 하루 10건, `health_notes.review` 통과분만 공개). 지금 문제는 문장이 탭 아래
접힌 목록 안에 숨어 있어 안 보이는 것이다. 이 작업은 **3단계 화면 카드**만 만든다.

## 목표

- 보건소 탭(`#health`) 맨 위, 기존 "상시 운영 검진·건강관리" 위에 카드 "이번 주 보건소 추천"을 둔다.
- **서울 전체 줄**: 사업 종류별로 운영하는 구 수를 센다. 예: `대사증후군 검진·관리 12개 구 · 임신 준비 검사 10개 구 · …`.
  종류를 누르면 그 종류를 운영하는 구만 남도록 카드 안 구 목록을 거른다(다시 누르면 해제).
- **구별 줄**: 수집되는 구마다 한 묶음. 각 묶음에 사업 최대 3개, 각 사업은 AI 문장의 **첫 문장**과 원문 링크.
  문장이 없으면 사업 이름과 링크만.
- **이번 주 표시**: 최근 7일(KST 오늘 포함) 안에 `hint` 공지가 있는 구에 "새 공지 N건" 표시를 붙이고 위로 올린다.
- 모바일 우선. 기존 장보기·혜택 카드 스타일과 맞춘다.

## 비목표 / 금지

- 새 유료 호출, 새 AI 공개 예외, 한도 변경 없음(보건소 문장 하루 10건 그대로).
- 백엔드·수집·`briefing.json` 구조 변경 없음. 프런트가 이미 공개된 `health_notices.programs`·`items`·`health_notes`만 묶는다.
  따라서 `publish.py`·`public_snapshot.py`·`policy_sha256`는 건드리지 않는다.
- 코드가 "무료"를 새로 단정하지 않는다. 종류 이름은 중립 표현(예: "대사증후군 검진·관리", "임신 준비 검사")으로 쓴다.
  임신 준비는 검사비 지원이라 무료가 아니다. "무료"는 AI 문장(검사 통과분) 안에서만 나온다.
- 수집 안 되는 11개 구(robots 차단 등)는 카드에 넣지 않는다(기존 아래 목록에 이미 사유와 링크가 있다).
- 실패·확인 지연(10일 초과) 사업은 세지도, 보이지도 않는다.

## 데이터 규칙 (프런트, `frontend/src/health.ts`)

입력은 기존 `parseHealth` 결과(`HealthBundle`)와 오늘 KST 날짜. 새 순수 함수 `weeklyPicks(bundle, todayKst)`.

- **대상 사업**: `status==='checked' && !stale`.
- **종류 분류**(사업 이름 단어, 위에서부터 첫 일치). 2026-11-12 공개 62곳 이름 기준:

  | 종류 키 | 표시 이름 | 이름 단어 |
  |---|---|---|
  | metabolic | 대사증후군 검진·관리 | 대사증후군 |
  | pregnancy | 임신 준비 검사 | 임신, 신혼부부, 예비부부 |
  | youth | 청년 1인가구 검진 | 청년 |
  | mind | 마음건강검진 | 마음건강 |
  | mobile | 모바일 헬스케어 | 모바일 |
  | smoking | 금연클리닉 | 금연 |
  | tb | 결핵검사 | 결핵 |
  | hepatitis | 간염검사 | 간염 |
  | basic | 기초 건강검사 | 골다공증, 골밀도, 체성분, 혈액, 기초건강, 무료건강검진 |

  어느 것에도 안 맞으면 종류 없음: 서울 전체 줄에서는 빠지고, 구별 줄에는 그대로 보인다.
- **서울 전체 줄**: 종류별 구 수(같은 구에 같은 종류 둘이면 1), 구 수 내림차순, 같으면 표 순서. 1개 구 이상인 종류만.
- **첫 문장**: AI 문장을 첫 `.`·`!`·`?`(바로 뒤가 공백 또는 끝)에서 자른다. 숫자 사이 점(`1.5`)은 끝으로 보지 않는다.
  자른 결과가 12자 미만이면 원문 문장 전체를 쓴다.
- **구 안 사업 순서**: 문장 있는 사업 먼저, 그다음 종류 표 순서, 그다음 이름 가나다. 최대 3개, 나머지는 "외 N곳".
- **구 순서**: 새 공지 있는 구 먼저 → 문장 있는 사업 수 내림차순 → 구 이름 가나다.
- **새 공지**: `items` 중 `hint && date >= todayKst-6일 && date <= todayKst`, 구별 건수.

## 화면 (`HealthSection.vue` 또는 새 컴포넌트 `HealthWeekly.vue`)

- 제목 "이번 주 보건소 추천", 오른쪽 작은 "AI 작성" 표시는 문장이 하나라도 보일 때만.
- 안내 한 줄: "AI가 공식 페이지를 요약했습니다. 대상·기간·비용은 원문에서 확인하세요."
- 구 묶음은 기본 4개 구까지 펼쳐 보이고 "구 더 보기"로 나머지를 연다. 위쪽 지역 필터를 고르면 그 구만 보인다(기존 `district` 상태 공유).
- 종류 칩은 버튼(`aria-pressed`), 탭 영역 44px 이상. 링크는 새 창, `rel="noopener noreferrer"`, 스크린리더용 "(새 창)".
- 보일 사업이 하나도 없으면 카드를 그리지 않는다.
