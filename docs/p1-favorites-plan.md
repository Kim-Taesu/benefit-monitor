# P1: 즐겨찾기와 검색 조건 공유

- 이 브라우저에 공개 항목의 식별자(source + 공식 URL)만 최대 200개 저장한다. 제목·혜택 내용·개인정보는 저장하지 않는다.
- 카드 저장/해제, 즐겨찾기만 보기, 모두 해제를 제공한다. 서버·로그인·계정 동기화는 없다.
- 즐겨찾기 목록도 기존 adapt의 파일/항목 만료·재검증·공식 URL 검사를 통과한 현재 항목에서만 파생한다.
  더 이상 표시되지 않는 ID는 종료로 단정하지 않으며 저장된 스냅샷을 되살리지 않는다.
- 검색 조건 공유는 현재 검색·지역·분야·정렬·상태만 복사한다. 저장된 관심 설정/즐겨찾기 ID는 공유하지 않는다.
  Clipboard 실패 시 선택/수동 복사 가능한 읽기 전용 링크를 제공한다. 타인에게 메시지를 보내지 않는다.
- 저장 차단/손상/한도 초과 시 성공으로 표시하지 않는다. 잘못된 저장값도 모두 해제로 제거할 수 있다.
- 즐겨찾기 보기에서 마지막 항목을 해제할 때 목록 제목으로 키보드 포커스를 이동한다.
