# AI 모델 API 도입 검토 — 2026-11-04

상태: 검토만 진행. 키 발급·조회·저장, API 호출, 결제 설정, 클라우드 생성은 하지 않았다.
현재 AGENTS.md는 추가 지출 0원, LLM API 호출 금지, 표준 라이브러리·익명 공식 페이지 한정을 요구한다.
API 키를 고려한다는 말만으로 이 정책이 바뀌지는 않는다. 무료 티어도 외부 LLM 호출 예외 결정이 필요하다.

## 권장 역할

기존 수집기 → 본문 추출 → 변경된 본문만 AI가 구조화 초안 작성 → 기존 스키마 검증 → 사람 승인 → 공개 출력.
AI는 기간·비용·결제 재원·최소 지출·대상 조건을 원문 위치와 함께 제안한다. 원문에 없는 값은 unknown으로 둔다.
AI 결과는 needs_recheck=True 후보로만 취급하고 verified_at/public_release를 생성하거나 갱신하지 못하게 한다.
재고·자격·신청 성공을 추정하지 않는다. 공식 사이트 접근 실패·robots 제한은 AI가 해결하거나 우회할 문제가 아니다.

키는 브라우저/VITE 변수/공개 저장소/briefing-data/로그에 넣지 않는다. 승인 후 필요하다면 기존 Actions의
저장소 secret에서만 주입하고, 요청에 공개 공식 본문만 넣는다. 웹 검색·브라우저·별도 에이전트 도구 호출은
예상 비용과 접근 통제를 늘리므로 첫 평가 범위에서 제외하는 방안을 권장한다.

## 비용 예시(실측·견적 아님)

가정: 하루 100개 변경 본문, 월 30일, 건당 입력 4,000토큰·출력 800토큰.
월 입력 1,200만·출력 240만 토큰이며 표준 토큰 요금만 계산한다. 페이지 수가 아니라 실제 토큰으로 과금된다.

| 비교 후보 | 입력/출력 USD·100만 토큰 | 가정상 월 토큰 비용 |
|---|---|---|
| GPT-6 Luna | 0.10 / 0.50 | $2.40 |
| Claude Haiku 5.5 (입력 10만 토큰 이하) | 0.10 / 0.50 | $2.40 |
| Gemini 2.5 Flash-Lite | 0.10 / 0.40 | $2.16 |

출처(2026-11-04 공식 문서 열람):
- https://developers.openai.com/api/docs/pricing
- https://platform.claude.com/docs/en/about-claude/pricing
- https://aistudio.google.com/docs/pricing

실제 제공 여부·계정별 제한·가격은 도입 시 다시 확인한다. 토크나이저·추론·재시도·이미지·도구·환율·세금은
실제 비용에 영향을 준다. 이 표는 그 추가 비용을 포함하지 않는다. 기존 ChatGPT/Codex·실행 환경 요금도
프로젝트가 보장하지 않으며, 구독만으로 API 비용이 자동 충당된다고 가정하지 않는다.

Gemini 문서에는 일부 모델의 무료 입력·출력 티어가 있지만, 사용 한도와 제품 개선에 대한 데이터 사용 조건이
있다. 무료 티어 여부와 결제 연결 상태를 실제 계정에서 확인하기 전까지 0원을 보장하지 않는다.

## 도입 전 필요한 결정과 평가

1. 기존 금지 정책에 외부 LLM 호출 예외를 둘지, 월 추가 지출을 0원으로 유지할지 결정한다.
2. 공식 본문 표본으로 날짜/마감, 자격, 비용/최소 결제, 포인트/할인 단위, 추첨/확정 지급을 구분해 평가한다.
3. 후보별 오류율과 검토 소요시간, 실제 토큰/지연/재시도 수를 비교한 뒤 모델을 선택한다.
4. 유료 사용을 승인하는 경우 월 예산·호출수·입출력 토큰 상한과 초과/오류 시 중단 방식을 먼저 확정한다.
   공급자 한도가 알림인지 강제 차단인지 확인하고, 로컬 제한만으로 공급자 청구 상한을 보장한다고 표현하지 않는다.
5. 승인 전까지 운영 코드에는 LLM 클라이언트·키 환경변수·네트워크 호출을 추가하지 않는다.
