# P1: 출처 정책 생성 명령

기존 Python 표준 라이브러리와 JSON 형식의 sources.yaml/districts.json을 사용한다.
`python scripts/generate_source_policy.py`는 프런트엔드가 이미 소비하는 maxAgeDays,
출처 ID별 name/domains, 자치구 이름만 결정적으로 투영한다. 그 외 설정·원문은 출력하지 않는다.
`--check`는 파일을 바꾸지 않고 불일치/누락을 실패로 반환한다. 루트 기본값은 스크립트 위치 기준이다.

유효기간은 양의 정수이고 출처 ID·자치구 이름·출처 안 도메인은 중복되지 않아야 한다.
표시 이름은 비어 있지 않아야 하며, 서로 다른 출처가 같은 이름·도메인을 공유할 수 있다.
도메인은 URL·와일드카드·인증정보·포트가 없는 소문자 ASCII 호스트만 받는다.
이는 문법 검사이며 공식 소유 여부를 검증하거나 새 호스트를 승인하는 절차가 아니다.
입력 오류 시 기존 정책 파일을 유지하고, 정상 생성은 같은 폴더의 임시 파일에서 원자 교체한다.
출력 symlink를 거부한다. 생성 결과는 기존 source-policy.json과 바이트까지 동일해야 한다.

기존 독립 정책 동기화 테스트를 유지하고, 생성/검사 CLI·불일치·잘못된 입력·비공개 필드 미출력을
회귀 테스트한다. PR CI와 일일 빌드에서 프런트엔드 빌드 전 --check를 실행한다.
네트워크 요청, 새 의존성, 수집/승인/배포 정책 변경은 없다.
