# P1: 본문 조건을 보존하는 변경 감지와 이용료 중립 수집

- 기존 main/article 의미 영역을 우선하되 하나로 특정할 수 없으면 문서 전체 텍스트를 비교한다.
- script/style/nav/footer만 제외한다. 본문 안의 조회/공감 숫자, 후기·신청 건수, 관련기사처럼 보이는 문구는 지우지 않는다.
  잘못된 자동 삭제로 금액·자격·기간 변경을 놓치는 것보다 보수적으로 재검증을 요청한다.
- 파서는 Python HTMLParser만 사용하고 깊이를 제한한다. 외부 자원·이미지·JS는 실행/요청하지 않는다.
- 해시 버전 3을 기록한다. v2 해시가 있으면 기존 알고리즘으로도 이번 페이지를 비교해 전환 중 알려진 변경을 놓치지 않는다.
  v3 첫 기준은 baseline이며 사실 재검증이나 과거와 같다는 의미가 아니다. verified_at은 갱신하지 않는다.
- 본문 영역(main/article/document)과 baseline/same/changed만 운영 메타데이터에 남긴다. 원문·URL을 저장하지 않는다.
- 공유누리 요청의 free_yn 필터를 제거하고 설정·수집 범위 문구를 맞춘다. 이전 free=True 설정도 무료 필터를 만들지 않는다.
  유료/무료 자원 모두 검증 전 후보이고, 이용료/잔여석/개인 자격을 확정하지 않는다.
- HTTP 예산/robots/TLS/허용 호스트/기존 캐시·대기시간/실행당 본문 확인 상한은 바꾸지 않는다.

네트워크 없는 파서/수집 요청 모의 테스트, v2→v3 전환·본문 금액/조건 변경·영역 밖 노이즈·실패/메타데이터 보존,
전체 Python 회귀 및 기존 프런트 CI를 검증한다. 실제 사이트 구조 전수 검증·새 출처 연결은 하지 않으며 후속 범위로 남긴다.
