# P1: 단말 관심 지역·분야 저장

P0 다음 첫 백로그 항목만 구현한다. 저장 대상은 지역과 분야 두 문자열이며 검색어·혜택 본문·개인정보는 저장하지 않는다.
로그인·서버·유료 서비스 없이 localStorage에 명시적으로 저장하고 삭제할 수 있다.

- 첫 방문의 지역/분야 선택을 사용자가 '현재 지역·분야 저장'으로 기억하도록 한다.
- 다음 방문에 URL 필터가 전혀 없을 때만 저장값을 기본값으로 사용한다.
- 공유 링크에 검색/지역/분야/정렬/상태 중 하나라도 있으면 링크를 우선한다.
- 데이터에 현재 없는 지역/분야도 저장 문자열 그대로 보존하며 전국/다른 범위로 확대하지 않는다.
- 저장 차단·손상·버전 불일치 때 앱 탐색을 유지한다. 저장 실패를 성공으로 알리지 않는다.
- 저장값 삭제는 현재 검색 링크를 변경하지 않는다. 필터 초기화는 기존 버튼으로 별도 수행한다.
- 관심 설정은 하단의 접근 가능한 details에 배치해 P0 첫 카드 노출을 유지한다.

검증: Node 저장/복원/삭제/손상/권한 오류/URL 우선 테스트, Chromium 재방문/공유 링크/삭제 테스트,
Python 전체 회귀 및 기존 화면·접근성 테스트. 별도 PR로 제시하며 새 PR은 승인 없이 main에 병합하지 않는다.
