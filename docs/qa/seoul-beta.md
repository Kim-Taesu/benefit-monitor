# 서울 개인화 공개 베타 — API 연결 전 검증

## 구현 범위

- 25개 거주 자치구 + 복수 관심 자치구, 선택적 만 나이(14–120), 통신사, 관심사.
- 규칙 기반 주제 후보, 연관된 기존 검증 혜택, 추천 이유와 미확인 자격 조건.
- 현재 표시 가능한 데이터만 사용. 만료·미검증·수집 실패 데이터는 기존 adapt() 게이트를 통과하지 못함.
- 서울/전국 범위로 기본 웹 목록을 제한. 기존 JSON/Markdown·수집기·미러의 계약은 변경하지 않음.
- 프로필과 선택 동의한 행동 기록은 localStorage에만 저장. 이벤트는 주제 ID/행동 종류/시각만 포함.
- 검색어 원문·연령·거주지·통신사·혜택 원문을 이벤트에 복제하지 않음. 외부 전송 없음.
- 노출은 화면의 주제 영역에서 화면에 50% 이상 보인 카드에 대해 방문당 1회. 최대 30일/500건, 다음 접속 시 만료 기록 정리.
- 동의 철회/삭제 실패에도 현재 탭 학습 중단. 저장소 잔존 시 사이트 데이터 수동 삭제 안내. 다른 탭 storage 이벤트 동기화 및 기록 직전 동의 재확인.
- 20회 미만 노출은 자료 부족; 이후 반응 기반 자동 주제 순위 변경. 직접 선택한 주제는 유지. 기준은 실험용이며 클릭은 실제 혜택 사용 증거가 아님.

## 확인한 내용

- 로컬 Node 단위 테스트: 47개 통과.
- 로컬 Python 회귀 테스트: 189개 통과.
- 출처 정책 생성 일치 검사 통과.
- 로컬 의존성 설치 후 Vue 타입/빌드와 기존 Chrome을 이용한 브라우저 테스트 37개(axe·키보드·모바일 포함)를 통과했다. GitHub CI에서도 기존 검증을 유지한다.
- 독립 리뷰에서 발견한 나이 입력 타입, 철회 실패, 다중 탭 기록 부활, 전국 안내 누락을 보완. 폼도 Profile 타입으로 유지.
- 브라우저 최종 결과와 실행 링크는 PR #16에 기록.

## 시험 방법

상단 주제 카드를 선택하면 기존 혜택 목록이 해당 주제로 좁혀진다. `내 지역·통신사·관심사 설정`을 펼쳐 설정하고, 행동 기록을 선택적으로 켜서 피드백/로컬 반응을 확인한다. `전체 주제 보기`는 주제 필터만 해제하며 다른 검색 필터는 유지한다. 부분 수집 안내는 페이지 하단에 표시한다. 만료된 공개 데이터로는 주제도 표시하지 않는다.

스크린샷은 합성 QA 데이터로만 생성하며 실제 혜택을 뜻하지 않는다. CI 아티팩트의 beta-390.png / beta-1440.png 및 기존 360/390/768/1440 검증 화면 참고. 아티팩트 보관은 기존 정책대로 1일.

## 남은 작업 / 공개 범위의 한계

- 전체 사용자 데이터 수집·운영자 피드백 전달은 아직 없음. 화면에 로컬 전용임을 명시. 운영자 통합 분석 로직은 합성 이벤트 단위 테스트로만 검증.
- 실제 AI 추천/새 주제 생성 없음. 유한 주제 목록과 문구 기반 후보 연결이므로 부정문·복합 예외·소득·기준일 등 신청 자격을 확정할 수 없음.
- 사용자 피드백 반영: 주제 카드는 상단에 바로 노출하고 설정만 접는다. 별도의 중복 혜택 목록은 제거했다. 모바일 첫 화면 발견 기준은 첫 주제 카드가 보이는지로 검사한다.
- 25개 구 전체 공지 수집을 보장하지 않음. 공공데이터 인증키/출처별 이용허락/실제 구별 유효 건수 확인이 필요.
- 서버 저장·AI·공공데이터 API·인프라 이전은 별도 단계. 연결 시 개인정보 안내/보관/삭제/국외 이전, 키 보관·비용 상한을 별도 검증.
- 14세 미만 개인화 입력과 자동 나이 갱신은 지원하지 않음. 기본 혜택 탐색은 프로필/동의 없이 가능.

## 주제 우선 화면 수정 검증

로컬 Vue 타입/빌드, Node 47개, Python 189개, Chrome 브라우저 37개 통과. 주제 선택 → 기존 목록 필터링 → 전체 주제 해제, 부분 수집 안내 하단 위치, 기존 검색·즐겨찾기·만료 상태와 axe/키보드 회귀를 확인했다. 실제 데이터 로컬 화면에서도 야간 주제 선택 시 관련 4건으로 좁혀짐을 확인했다.

카드 최소 높이를 데스크톱 124px / 모바일 126px로 줄이고, 기본 8개 이후는 더 보기로 펼친다. 직접 선택한 관심 주제는 유지한다. 2026-11-04 로컬에서 확인한 기존 표시 데이터 기준 상품권 4건, 편의점 4건, 걷기·러닝 4건, 가족 체험 3건, 주거 모집 3건, 일자리 3건의 주제를 추가했다. 주제 간 중복이 있으며 자격·잔여석을 확정하는 수치가 아니다. 새 주제는 요약 본문으로 연결해 조건 문구만 등장하는 무관한 공고를 제외한다.
