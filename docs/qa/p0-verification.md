## 보존한 계약

Python 수집/승인/공개 JSON·MD·briefing-data 미러 로직과 schema_version 1 유지.
기존 cron 0 16 * * *, noindex/nofollow 및 공개 저장소/무과금 확인 게이트 유지.
공식 URL은 출처별 정확한 HTTPS 호스트 허용 목록으로 검사하고 Vue 기본 텍스트 이스케이프 사용.
만료·미검증·실패 자료를 현재 추천으로 게시하지 않으며 비용으로 추천을 우대/제외하지 않습니다.
새 서비스·유료 API·서버·로그인·결제·추적 분석을 추가하지 않았습니다.
ChatGPT/Codex 및 기존 실행 환경의 요금은 이 프로젝트가 보장하지 않습니다.

로컬 환경은 npm/GitHub 직접 DNS 연결과 loopback 서버 바인딩이 제한되어 있어 운영 빌드와 브라우저 검사는
기존 무과금 게이트가 적용되는 공개 Actions의 표준 ubuntu-24.04 runner에서 실행했습니다.
기존 로컬 파일을 보존하기 위해 프로젝트 폴더 안 .maintenance/p0-source의 일반 소스 사본에서 작업했습니다.
worktree 또는 프로젝트 폴더 밖의 파일을 만들지 않았습니다. 운영 배포·main 병합은 수행하지 않았습니다.
