# Benefit Monitor 2.0 후속 백로그

P0는 공개 JSON 탐색 UI, 상태 검사, 접근성, 정적 배포 호환성까지입니다. 현재 수집·검증 범위를 늘렸다는 의미가 아닙니다.

| 우선순위 | 항목 | 수용 조건 |
|---|---|---|
| P1 · 완료 (#10) | 단말 관심 지역·분야 저장 | localStorage 한정, 초기화 가능, 개인정보·로그인 불필요 |
| P1 · 완료 (#11) | 즐겨찾기와 공유 버튼 | 현재 검색 URL 재사용, 만료 항목 안전 처리, 단말 한정 안내 |
| P1 · 완료 (#12) | 공식 근거가 있는 금액·절약액 필드 | 승인·검증·스키마 테스트 선행, 숫자 추정 금지 |
| P1 · 완료 (#13) | 본문 조건 보존·이용료 중립 수집 | 숫자 조건 보존, v2 전환 비교, 무료 항목 제한 제거, 기존 요청 예산 유지 |
| P1 · 일부 진행 | 출처별 파서 확장·실제 구조 검증 | 공식 페이지 표본을 요청 예산 내 확인, 이미지·JS 조건 한계 명시, 새 출처는 별도 승인·정책 검증 |
| P1 · 완료 (#14) | 출처 정책 생성 명령 | 결정적 생성·비수정 --check, 잘못된 입력 보존, PR/일일 빌드 검사 |
| P1 | 운영 사용자 10초 발견 과제 평가 | 실제 사용자의 발견 성공률·소요 시간 기록, 유료 분석기 불필요 |
| P1 | 읽기 화면의 CSP와 배포 캐시 검증 | self 호스트 번들만 허용, Vue와 접근성 테스트 호환성 확인 |
| P2 | 혜택 비교·예상 절약액 | 검증된 금액/조건만 계산, 비용·최소 결제액·한도 구분 |
| P2 | AI 파싱 평가 | 현재 금지 정책 아래 실행하지 않음. 무료 로컬 평가 가능성만 별도 검토; 유료 API/클라우드 자원은 도입 금지 |
