# 구조화 출력 전송 계약 — Phase 1, 2026-11-05

상태: **2026-11-06 첫 실제 요청이 문법 크기 초과로 거절됨 → 유니온·정규식 제거판으로 교체, 실측 대기**. 실제 확인은 main 병합 뒤 클라우드 일일 실행에서 한다. 이 문서는 모델 품질 통과를 뜻하지 않는다.

## 왜 바꿨나

[Phase 0 기준선](evaluations/baseline-2026-11-05/README.md)에서 조사 거절 20건 중 12건이 형식 문제였다. 전에는 JSON 스키마를 시스템 프롬프트에 글로 붙였고 모델이 그 형식을 지키는지는 사후 검사로만 확인했다. 이제 Claude API의 구조화 출력이 응답을 스키마에 맞게 강제한다.

## 요청 모양

```json
{"model": "claude-haiku-5-5", "max_tokens": 8192, "thinking": {"type": "disabled"},
 "system": "<docs/ai/prompts/*.md>",
 "output_config": {"format": {"type": "json_schema", "schema": {}}},
 "messages": [{"role": "user", "content": "<모델용 입력 JSON>"}]}
```

- 시스템 프롬프트는 [조사용](prompts/research-system.md)과 [주제용](prompts/topic-system.md) 전용 파일이다. 운영 이력, 승인 기록, 진행 단계 표는 넣지 않는다.
- 스키마는 `benefit_monitor/wire_format.py`가 만든다. 조사용 스키마는 고정이라 공급자 캐시를 재사용한다. 주제용 스키마는 그날 입력에 따라 바뀐다.
- 첫 요청은 스키마 컴파일 때문에 느릴 수 있어 응답 대기 한도를 300초로 늘렸다.
- 공통 모양(근거 배열)은 `$defs`에 한 번만 두고 `$ref`로 참조한다. 공급자는 인라인 사본을 모두 펼쳐 프롬프트에 넣기 때문이다.

## 2026-11-06 거절과 교체

첫 실제 조사 요청이 HTTP 400 `The compiled grammar is too large`로 거절됐다. 토큰 계산 사전검증은 통과했었다. 공식 문서는 유니온(`anyOf`)이 컴파일 비용을 지수적으로 키우고 복잡한 정규식도 400을 낼 수 있다고 적는다. 당시 조사 스키마는 사실마다 "확인/미확인" 두 모양을 고르는 유니온 14개(한도 16)와 정규식 5개를 가졌다.

교체판은 유니온 0개, 정규식 0개다. `check_limits`가 둘 중 하나라도 있으면 요청 전에 거부한다.

- 조사: 모든 사실이 `status`(supported, disputed, unknown), `value`, `evidence`, `unknown_reason` 네 칸을 항상 가진다. unknown이면 호스트가 value와 evidence를 버린다. unknown인데 사유가 비었거나, 확인 사실에 근거가 없거나, 날짜·시각 형식이 틀리거나, 확인된 자치구가 비었거나, availability가 unknown이 아니면 호스트가 거절한다. 없는 조각 ID도 그대로 거절한다.
- 주제: 주제별 분기 대신 주제 ID와 항목 ID를 평평한 목록으로 두고, 그 주제에 허용되지 않은 항목을 고르면 호스트가 거절한다.
- 같은 날 무료 사전검증: 조사 입력 1건이 11,543토큰으로 받아들여졌다. 문법 컴파일 확인은 다음 실제 요청에서 한다.

## 무료 사전검증

실제 요청 전에 같은 본문을 [토큰 계산 API](https://platform.claude.com/docs/en/build-with-claude/token-counting) `/v1/messages/count_tokens`로 먼저 보낸다. 공식 문서상 무료이고 메시지 생성과 별도 한도다. 모델 출력이 없고 원장 예약·요청 수·노출액을 바꾸지 않는다.

- 공급자가 요청 모양을 거절하면(HTTP 4xx) 예약 전에 멈춘다. 사유는 키를 가린 채 `.tools/claude-trial/live/preflight-failures.json`에 남고 클라우드 상태 묶음에 함께 보존된다.
- 연결 실패나 이상한 응답도 예약 없이 멈춘다. 그 후보는 기존 규칙대로 같은 프롬프트에서 다시 시도하지 않는다.
- 통과하면 추정 입력 토큰을 실행 `metadata.json`의 `preflight`에 기록한다. 실제 `usage`와 비교할 수 있다.
- 수동 확인: `python3 -m benefit_monitor.claude_trial preflight --root . --kind research --input <입력>`

## 공급자 제약과 확인 방법

[공식 구조화 출력 문서](https://platform.claude.com/docs/en/build-with-claude/structured-outputs)를 2026-11-05에 확인했다.

| 제약 | 공급자 한도 | 조사 스키마 | 주제 스키마 |
|---|---:|---:|---:|
| 유니온 타입 파라미터 | 16 | 14 | 1 |
| 선택 파라미터 | 24 | 0 | 0 |
| minLength 같은 미지원 키워드 | 사용 불가 | 0 | 0 |

`check_limits`가 요청 전에 이 값을 계산한다. 한도를 넘으면 비용 예약 전에 중단하므로 요청 수도 차감하지 않는다. 빈 문자열 금지 같은 미지원 제약은 기존 로컬 검사가 맡는다.

## 모델이 쓰는 것과 호스트가 채우는 것

| 항목 | 전 | 후 |
|---|---|---|
| 조사 근거 | 모델이 인용문을 글자 그대로 복사 | 모델은 문장 조각 ID만 고르고 호스트가 원문 조각을 인용으로 붙임 |
| unknown 사실 | 값과 근거를 비워야 한다는 규칙을 모델이 지킴 | 스키마에 값·근거 칸이 아예 없음 |
| 날짜 | 자유 문자열 | 날짜와 시각 패턴으로 제한 |
| 자치구 | 자유 문자열 | 서울 25개 구 목록 중 선택 |
| 주제 제목 | 모델이 작성 | 호스트가 표준 제목을 붙임 |
| 주제 항목 | 모든 ID 가능 | 호스트 편집 근거가 그 주제를 허용한 항목만 선택 가능 |
| 근거 claim ID | 모델이 작성 | 호스트 편집 근거에서 붙임 |
| 스냅샷 ID, 카드 전체 연령 조건 | 모델이 작성 | 호스트가 붙이고, 연령 조건은 쓰지 않음 |

호스트는 응답을 기존 v3 조사 계약과 topic-draft-v1 계약으로 되돌린 뒤 기존 검사를 그대로 돌린다. 인용 대조, 제한 문구 보존 검사, 날짜·만료 검사, 주제 의미 검사는 바뀌지 않았다. 없는 조각 ID나 빈 미확인 사유는 지우지 않고 거절한다.

## 알려진 한계

- 인용이 최소 구절이 아니라 문장 단위가 된다. 검토자는 문장 전체를 보게 된다.
- 주제 제목은 표준 제목 13개만 나온다. "주말 가족 무료 문화 체험" 같은 자유 제목은 더 이상 만들지 않는다.
- 같은 주제를 두 번 내거나 같은 항목을 포함과 제외에 함께 넣는 오류는 스키마로 막지 못한다. 기존 검사가 거절한다.
- 의미 오류는 이 변경으로 줄지 않는다. Phase 3에서 다룬다.
- `parse_draft`의 코드펜스 허용은 이전 응답 재생 때문에 남겨 두었다. 구조화 출력 응답에는 코드펜스가 없다.
- 기존 요청 헤더 `anthropic-version: 2023-06-01`과 `output_config`, `$ref`는 2026-11-05 무료 사전검증에서 조사 2건, 주제 1건 모두 받아들여졌다. 토큰 계산은 문법 컴파일까지 보장하지 않으므로 첫 실제 생성 요청에서 최종 확인한다.
- 토큰 계산값은 추정치이고 공급자가 넣는 비과금 토큰을 포함할 수 있다. 과금 기준은 실제 응답의 `usage`다.

## 무료 토큰 측정 — 2026-11-05

같은 원문 17건(기록된 조사 입력 15건 + 현재 대기 2건)에 대해 옛 요청(운영 문서 프롬프트 + 원문 + 글로 붙인 스키마)과 새 요청을 `count_tokens`로 쟀다. 원장은 30회, 106,768 microUSD 그대로였다.

| 구성 | 토큰 |
|---|---:|
| 옛 시스템 프롬프트 | 10,373 |
| 새 시스템 프롬프트 | 1,891 |
| 구조화 출력 스키마, 인라인 | 8,218 |
| 구조화 출력 스키마, `$defs` | 5,369 |
| 문장 조각 ID 추가분, 평균 | 271 |
| 조사 요청 평균, 옛 → 새 | 13,278 → 10,437 |

스키마를 JSON 글로 넣으면 4,414토큰인데 구조화 출력은 인라인 스키마를 8,218토큰으로 펼쳤다. `$defs` 적용이 가장 큰 절감이었다. 날짜·조각 ID 패턴을 지우면 최대 289토큰을 더 줄일 수 있지만 형식 보호를 잃어 유지했다.
