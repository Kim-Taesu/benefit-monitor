## 범위와 방법

## 수정 결과

- R10: source 정보 부재가 아닌 draft 요약 누락임을 계약에 구분했다.
- R12: 접수 종료를 행사 전체 종료와 구분했다.
- V08: 존재하지 않는 근거 ID를 유효 evidence 목록에서 분리했다.

- 블라인드 평가: packet 해시뿐 아니라 case별 arm 매핑도 검증해 키의 A/B 출처 뒤집기를 거절한다. 보안 암호화가 아니라 실수 검출이며 평가자는 키를 보지 않는다.

수정 후 독립 재검토에서 위 항목의 해소를 확인했다. 실제 게이트 35/35 기대 일치. 변경 전후 보고서를 보존하며 최신 기준선은 `baseline-*-reviewed-2026-11-14.json`이다.

## 계측 검토

추가 계측에 대해 별도 읽기 전용 검토를 수행했다. `stopped_before_result`를 정상 추출로 집계하던 문제와 저장 실패 후 stderr 오류가 원래 결과/예외를 덮는 문제를 테스트로 재현하고 수정했다. subprocess 최초 검증이 부모 ContextVar를 공유하지 않는 한계는 평가 안내에 명시했다. 추출 시간은 subprocess 전체 시간이며 개별 provider 지연으로 주장하지 않는다.

수정 후 독립 reviewer가 두 오류 처리 동작을 재현하고 세 번째 계측 범위 문서화를 확인했으며 추가 지적은 없었다. 전체 테스트는 구현자가 실행한 결과이고 독립 reviewer의 재실행 결과와 구분한다.

로컬 전체 테스트와 비공개 아카이브 pack/restore 검사를 실행했다. age 실행 파일이 필요한 암호화 왕복 테스트는 이 워크트리에서 건너뛰었으므로 암호화 실행까지 검증했다고 표시하지 않는다.
