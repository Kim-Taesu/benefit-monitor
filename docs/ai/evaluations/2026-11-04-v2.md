# 보완 후 독립 시험 v2 — 2026-11-04

## 결론

고정 합성 자료의 조사 해석·근거 연결·주제 분류는 완료했다. 실제 추가 조사 시험은 DNS 오류로 중단되어 정상 경로를 검증하지 못했다. API 도입 준비 완료나 실제 한국어 공고 정확도 수치로 해석하지 않는다.

## 보완한 내용

- offline_fixture / read_only_research / 비활성 api_agent 모드 분리.
- 후보 ID 산식, 호스트 관측 문서 메타데이터, 승인 claim/snapshot 입력 전달 정의.
- 5개 합성 후보와 별도 승인된 주제 입력 제공. 연구 결과를 임의 승인하지 않음.
- 성공 records/topics와 missing_input·environment_unavailable 등의 오류 봉투 분리.
- 공식 호스트 내 운영기관·시민기자·AI 요약의 권위 구분.
- 유효 HTTP 예산, 시도/전송/성공의 구분, 첫 연결 오류 후 중단 정의.

## 시험 독립성

새 에이전트 두 개를 각각 fork_turns=none으로 실행했다. 이전 대화·이전 평가 결과는 전달하지 않았다. 지침과 호스트 입력만 제공했다. 메인 세션은 결과를 받은 뒤 별도 Python 검사와 수동 의미 대조를 수행했다.

- 고정 자료 에이전트: 후보 5개, 네트워크/API 0회.
- 실제 조사 에이전트: 버스 안내 후보 1개, HTTP 예산 10회. 첫 robots 요청 전 DNS 오류로 종료.
- 결과는 Codex 기반 문서 시험이다. 특정 API 모델의 성능·비용 시험이 아니다.

## 주제 결과

독립 승인 입력의 두 항목만 6개 기존 주제에 연결했다.
- 걷기 프로그램: local, age, night, outdoors.
- 가족 미술 체험: culture, family.
- 만료·충돌·미열람 첨부 후보는 전역 제외 목록에 남겼다.

6개 연결은 현행 주제 사전에 부합한다. outdoors는 사전에서 걷기를 포함하므로 연결한 것이며, 이 자료가 실외 장소를 명시한다는 뜻은 아니다. 장소 자체를 표시하려면 별도 근거가 필요하다. family 항목에는 승인 claim에 없는 서울 지역을 개인화 조건으로 추가하지 않았다. 유료 항목을 비용만으로 제외하지 않았다.

## 실제 조사 결과

robots.txt 전 DNS 단계에서 gaierror(Errno 8). 예산은 1 차감, 실제 HTTP 전송 0, HTTP 성공 0, 원문·보조 문서 0건, 재시도 0회다. TLS 연결 전 실패했다. 기록은 [live-result.json](v2/live-result.json), [live-notes.md](v2/live-notes.md)에 보존했다.

새 오류 봉투는 missing ID를 가진 가짜 성공 레코드를 생성하지 않고 records=[]와 environment_unavailable을 반환했다. 보류 동작은 확인했지만 공식 자료 추가 탐색·정정 공지 발견·실제 근거 추출 품질은 미검증이다. 외부 도구로 우회하거나 robots 확인을 생략하지 않았다.

## 남은 설계 항목

1. audit/proposed_fields/profile_conditions/supplemental의 기계 검증 가능한 상세 JSON Schema가 아직 없다. 에이전트가 notes에 합리적인 해석을 남겼지만 공급자별 변형이 생길 수 있다.
2. completed는 현재 작업 종료 의미다. 정상/악성지시 사례도 신청 방법 등 critical 미확인 질문이 남아 있다. 운영 단계에서 completed만으로 공개·주제 승격하면 안 된다. 후속 계약에는 execution_status와 evidence_readiness를 분리하는 것이 적절하다.
3. 시험에서 prompts.md의 배열 안내와 execution.md의 봉투 안내가 충돌했다. 에이전트는 실행 계약을 우선했고, 시험 후 템플릿 문구도 봉투 형식으로 정리했다. 이 변경은 출력 구조를 바꾸지 않는다.
4. 현재 fixture는 합성 5건이다. 실제 30건 평가·토큰 계측·공급자 비교는 아직 수행하지 않았다.
5. read_only_research 정상 경로는 공식 호스트 DNS/HTTPS가 가능한 실행 환경에서 재시험해야 한다.
