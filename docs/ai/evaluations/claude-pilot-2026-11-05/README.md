## 실제 실행과 비용

인증과 모델 목록 조회가 성공했고 `claude-haiku-5-5`로 실제 생성 응답을 받았다. 모든 요청은 Python 표준 라이브러리로 고정 Anthropic HTTPS endpoint에 전송했다. API 요청은 모델 목록 1회, HTTP 400 실패 2회, 생성 15회로 총 **18회**다. 추가 유료 호출은 중단했다.

| 실패 2건 미확정 예약액 | $0.030844 |

계산액은 청구서·세금·계정 잔액 확인값이 아니다. 실패 호출의 실제 청구 여부는 미확인이라 예약액을 해제하지 않았다. 로컬 원장은 전송 전 최대 비용을 예약하고 usage 누락·오류·예상 밖 요금 모드에서 중단한다. 계정 한도는 사용자가 설정했다고 보고했으며 API로 별도 확인하지 않았다. ChatGPT/Codex와 기존 실행 환경 요금은 이 프로젝트가 보장하지 않는다.

## 조사 품질

기존 사람 검토를 거친 공식 원문 9건을 재생했다. **완전한 조사 출력 계약 통과는 0/9**다. 개별 사실 모두가 틀렸다는 뜻은 아니지만 그대로 다음 단계에 넘길 수 없다.

## 실험 한계와 다음 판단

개발 자료 재생이며 독립 보류표본·동일 예산 온라인 A/B·신규 발견 성능·Python 대비 품질 우위를 입증하지 않았다. 이번 생성 실험에서 혜택 원문을 새로 HTTP 조회하지 않았다. 기존 무료 수집기의 robots·허용 출처·요청 60/최대100·6시간 구 캐시·실패 쿨다운 정책은 그대로다.

다음 개선 후보는 모델 출력에서 호스트 소유 메타데이터를 분리하고, 공식 문서를 확인한 뒤 구조화 출력 지원을 검토하며, 주제·제목과 각 항목의 의미 일치를 검사하는 것이다. 청년 교류를 기존 취업 주제에 강제 연결하지 않도록 사전도 검토해야 한다. 아직 구현·재실험한 개선으로 주장하지 않는다. 더 비싼 모델로 자동 전환하지 않았다.

Phase0~4의 동결 자료와 최종 사람 승인 기록은 변경하지 않았다. 공개 데이터·승인 상태·배포·예약 작업·main에는 반영하지 않았다. 기존 브랜치의 선행 변경은 유지했다.
