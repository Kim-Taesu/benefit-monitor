[수정하지 않은 파서의 저장 본문 비교](parser-baseline.json)에서 이3개 기사 URL은 결과에 없다. 기존 이마트 뉴스만을 보던 범위에서 이마트24 기업 소식으로 확장한 `coverage_expansion`이며, URL 부재만으로 다른 URL의 동일 프로그램이 없다고 최종 확정하지 않는다. [기존 자료 해시](baseline-manifest.json)의 동결 원문에 대한 의미 단위 중복 검토는 최종 채점에서 재확인한다.

실제 요청·성공·실패·시각은 [회차3 원장](../../phase01/document-access-r03.json)을 따른다. 로컬 재판독은 새 HTTP 성공으로 세지 않는다.
