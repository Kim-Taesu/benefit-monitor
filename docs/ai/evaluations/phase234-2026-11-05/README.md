# Phase0~4 최종 결과 — 사용자 검토 반영

사용자 응답 **“최종 검토표 확인. 이슈 없음.”**을 반영해 Phase0~4 초기 개발시험 달성조건을 충족했다. [사람 검토 기록](human-final-review-result.json)과 [최종 평가](final-evaluation.json)가 현재 정본이다.

- 신규 후보: 문화·운동3 / 장보기·멤버십3 / 청년·1인가구3, 총9개 사용자 확인.
- 조건 조사: 사전등록 질문v2 11/20 해결·새 중요오류0 확인. 이전7/20·6/20·7/20과 미해결9개는 보존.
- 개인화: 프로필10개 전체 이슈 없음 확인을10/10 O(100%)로 정규화. 알려진 필수조건 위반0. 개별 점수 나열이나 검토 시간 실측을 받은 것은 아님.
- 출처 지도·비교 설계:25개 구와 기존15개 출처,30개 입력 확정. 확장 큐50칸 미확인은 유지.
- 무료 정책·기존 브랜치 유지. 추가 HTTP0회, 현회차54/60·누적174회. 과거 회차2 운영위반은 그대로 보존.

동결된 최종 검토표·후보·프로필·답변 원본7개는 변경하지 않았다. 그 안의 빈 점수·예비 상태는 검토 전 기록이다. 현재 점수는 별도 최종 평가를 읽는다. 온라인 동일 예산 A/B·일반 모델 성능·유료API 효과·실제 자격/재고/할인 성공·공개베타는 이번 완료 범위가 아니다. API과금·main병합을 승인받거나 실행하지 않았다.

최종 검증: [달성조건 검증 기록](completion-verification.json) 통과, 전체224개 테스트 통과, `git diff --check` 통과.

## 중복과 비교의 범위

[기존 자료 해시](baseline-manifest.json)에 고정한 공개·후보·검토 객체556개에서 문화·청년6개 서비스ID가 없음을 확인했다. URL만 다른 같은 행사 여부는 기관·프로그램·회차·기간으로 예비 검토했다. 장보기의 중복·기간 검토는 완료 판정하지 않았다.

[파서 비교](parser-baseline.json)는 실제 저장 본문에 수정하지 않은 Python 링크 파서를 적용했다. 문화·청년6개 URL은 그 결과에도 없었다. 기존 파서는 첫 화면 링크를 대상으로 하고 이번 조사는 분야별 하위 목록의 공식 상세 연결을 따라갔으므로 `coverage_expansion`이다. 파서를 약화하지 않았지만 온라인 A/B 실행·동일 예산의 모델 우위 입증은 아니다. 과거 저장 기사30건을 독립 표본으로 재사용하지 않았다.

## 고정 질문과 추천 초안

[질문20개](questions.json)는 추가 상세 문서 열람 전에 고정했다. [해결 기록](question-results.json)은 현재 완전 해결7개와 부분·미해결13개를 구분한다. 추가 공식 자료에서 강북 마감이11월23일00시로 나와 예약 페이지11월24일00시와 충돌했다. [이전8개 판정](question-results-r01.json)을 보존하고 재판정했다. 공식 무료 표기는 확인했어도 재료비 등 추가 비용의 모든 조건까지 확정하지 못한 질문은 해결 건수에 포함하지 않았다.

[가상 프로필10개](profiles.json)는 실제 개인정보가 아니다. v2에서는 지역·나이·관심사와 기존 통신사 멤버십을 연결했다. 17세에는19~39세 프로그램을 제안하지 않고 가상 기존 KT멤버십 아침 간편식 할인을 연결했으며, 나이를 모르는 이용자는 조건부 후보로만 제시했다. 기존 보조 혜택은 신규 발견 건수로 세지 않는다. [보조 조건 근거](supporting-memberships.json)와 [사람 검토표](personalization-review.md)를 함께 확인한다.

v1은 [별도 보존](profiles-v1.json)했다. 현재 사람 점수는 비어 있고 관련성90%를 주장하지 않는다. [검토표 해시](review-packet-lock.json)로 v2를 고정했으며 사용자에게 채점을 요청했다. 프로필을 조사 결과 열람 후 작성했으므로 개발 평가이며 전체 사용자 관련성의 통계적 보장이 아니다. 알려진 필수조건 로컬 대조는 관련성의 사람 채점을 대신하지 않는다.

새 질문 묶음은 [사전 등록](trial02-preregister.json)한 후6개 중2개의 상세를 읽었고 [현재2/20](trial02-results.json)을 해결했다. 첫 묶음의 실패를 보존하고 같은 질문 범위·20개 중10개 기준을 유지한다. 두 묶음의 해결 건수를 합쳐 분모20으로 보고하지 않는다.

## 요청·비용·다음 단계

첫 회차는 선행 진단4회·통과 진단3회를 합산해60/60에서 종료했다. 구청 실사 등 별도 목적의 두 번째 회차도60/60에서 종료했다. 전체 누적120회를 함께 기록한다. [첫 원장](../../phase01/source-audit-2026-11-05.json)과 [두 번째 원장](../../phase01/district-access-r02.json)을 따른다. 원문은 로컬 `.tools/phase01/`의 해시별 `.body`에 보관하며, 이를 다시 읽는 것은 새 HTTP 성공이 아니다.

TLS·기존 허용목록·2 MiB 상한·실패15분 대기·구별 운영6시간 캐시를 유지했다. 회차2 송파구 Crawl-delay 위반을 확인해 해당 자료를 격리했고, 운영 준수 판정은 실패로 기록했다. [사건과 교정](../../phase01/status.md)을 따른다. 공개 목록 조회 외 신청·예약·결제·로그인·접근 우회는 하지 않았다. 외부 LLM API0회, 추가 서비스 지출0이며 기존 Codex/ChatGPT·컴퓨팅 사용료는 프로젝트가 보장하지 않는다. 운영 설정·공개 혜택·main 병합·배포는 변경하지 않았다.

남은 작업은 기관 연결·실제 접근 보완, 잠근30칸 중14개 대상 문서 확보, 장보기3개 유효 조건 확보, 한 질문 묶음의10/20 달성, 중요 오류와 개인화의 독립 평가다. 별도 조사 회차를 시작할 때 실행ID·시각·예산·누적 요청을 남기고 운영 수집과 동시 실행하지 않는다. 같은 실행의 예산을 reset하여 조사량을 늘리지 않는다.

## 회차3 추가 판독·최종 검토 대기

현재 원장은44/60회·누적164회다. 두 번째 질문 묶음은 추가4개 상세 판독을 끝내6/20으로 갱신했고 초기2/20 결과도 보존했다. 질문v2를 먼저 등록한 네 번째 묶음은[11/20 예비 해결](trial04-results.json)이며 앞선 실패와 합산하지 않는다. 사람 중요오류 검증 전이다.

[사람 최종 검토표](final-human-review.md)에서 발견9개·해결조건11개·프로필10개를 검토할 수 있다. [동결 해시](final-human-review-lock.json)에 맞춰 사용자 점수를 요청했으며 채점 전 전체 통과로 처리하지 않는다. 최신 현재 판정은 [상태 문서](../../phase01/status.md)를 따른다.

## 원래 달성조건 최종 대조

[완료 대조](completion-audit.md)와 [생활 주제 카드](scenario-cards.md)를 추가했다. 현회차54/60회·누적174회이며 기관 지도는30기관연결·13공식프로그램·7공식디렉터리·미확인50칸이다. 사람 채점은 여전히 미입력이다. 원래 목표에 없는100개기관접근성공을 추가하지 않으며 선택적 탐색으로 사람 평가를 대신하지 않는다. 현재 증거로 전체 완료를 선언하지 않는다.
