# 4일 한정 활성화 검토안

상태: 사용자 `ok` 응답으로 검토 범위를 승인했다. 실제 활성화·검증을 진행 중이며 전체 목표는 미완료다. [승인 기록](activation-approval.json).

## 승인할 동작

| 항목 | 구체적 범위 |
|---|---|
| 기간 | 활성화 시각부터4일. `trial_expires_at`과 공개 편집 정책 만료를 같은 시각으로 설정 |
| 실행 | 이 Mac의 로그인 세션에서15분 간격 점검, KST06:00 이후 하루1회. Mac이 꺼져 있으면 실행을 보장하지 않음 |
| API | 하루 조사 최대2건·주제1회,4일 최대12회와 실제 검증 최대1회. 전체 누적40회·$5 중 먼저 도달한 한도에서 중단. 재충전·한도 초기화 없음 |
| 사실 승인 | AI는 추출·검증·비공개 검토 대기까지 담당. 계약 통과도 사람의 새 사실 승인을 대신하지 않음 |
| 공개 편집 | 이미 사람이 승인했고 현재 유효한 사실만 사용. 문화·체험→culture, 교육·강좌→learning, 할인·적립→shopping의3개 분류 정책만 허용. AI가 카드 구성·표준 제목·순서를 제안 |
| 공개 전달 | 개인 저장소 `Kim-Taesu/benefit-monitor`의 기존 `briefing-data`에 공개 JSON 반영. 기존 `docs/ai-research-playbook` 코드·정책 커밋 및 일반 push, 해당 브랜치의 기존 Pages workflow 실행 |
| 브랜치 | 기준 tree는 같지만 공통 조상이 없어 양쪽 이력을 보존하는 작업 브랜치 결합 필요. 강제 push·main 병합 없음 |
| Pages 설정 | 기존 `github-pages` 환경에 `docs/ai-research-playbook` 허용 브랜치 추가. 기존 공개 저장소·무료 실행 확인 변수·Pages 구성을 먼저 재확인. 새 자원·과금 설정 생성 없음 |
| Mac 설치 | 프로젝트 밖 예외는 `/Users/user/Library/LaunchAgents/com.benefit-monitor.ai-daily.plist` 한 파일 설치와 해당 job 등록에 한정. 다른 전역 설정 변경 없음 |
| 인증 | 저장된 개인 `Kim-Taesu` 계정만 지정·확인. 전역 계정 전환 없음. Claude 키는 로컬 프로그램만 읽고 GitHub·브라우저·공개 산출물로 보내지 않음 |

비활성 파일은 프로젝트 내부 `.tools/ai-activation-final-review/`에 준비했다. 검토용 설정·편집 근거·공개 승인 세 파일의 승인 값은 모두 false이며, 승인 후 실제 적용 파일을 별도로 생성했다. plist 형식 검사는 통과했으며 아직 설치하지 않았다. 실제 설치 전 프로젝트 내부 로그·임시 디렉터리를 준비하고 현재 검토 파일과 코드가 같은지 재확인한다.

## 현재 증거와 남은 확인

| 목표 | 현재 증거 | 완료 판정 |
|---|---|---|
| 실제 v3 재실험 | 이전 실패·새 개발 표본5건, 날짜별 주제2회, 별도 실제 수집 통합1회. [결과](README.md) | 실험 수행. 현재 조사0/5·주제1/2 통과로 자동 사실 승인 품질은 입증하지 못함 |
| 수집→변경→AI→검토 | 실제 공식 HTTP4회·API1회로 거절 결과를 비공개 대기에 저장. 공유 HTTP 예산·robots·캐시·쿨다운·누적 원장 테스트 | 연결 검증. 전 출처 조사 완료나 새 사실 자동 승인으로 해석하지 않음 |
| 승인 사실→카드→화면 | 사실·기한·보류·편집 근거 검사, 개인 설정 로컬 유지, Chrome43개 테스트로 표시·연결·만료 복귀 확인 | 로컬 검증. 실제 공개 전 |
| 일일 실행·원격 전달 | 하루 중복/중단 보호·기간 만료·명시적 승인 게이트. 고정 snapshot·코드 SHA와 깨끗한 배포 사본 검증 | 구현·모의 전달 검증. 실제 계정·workflow·Pages·LaunchAgent 활성화는 미실행 |

최종 실행 증거는 [checkpoint-verification.json](checkpoint-verification.json)이다. Python356개, 프런트 단위52개, Chrome43개와 타입 검사·빌드·공식 출처 정책·차이 공백 검사·Python 컴파일·plist 검사가 통과했다. 별도 formatter/linter 명령은 프로젝트에 선언돼 있지 않다.

기존 동결 자료14개와 과거 API 산출물108개·원장 앞19요청 해시를 재검증했다. 이번 검증에서는 API를 추가 호출하지 않았다. 누적27회, usage 계산액$0.067040, 실패 예약 포함 예산 점유$0.097884, 보수적 잔여$4.902116·13회다. 공급자 청구서·세금·계정 잔액 확인값은 아니다.

승인 후 실제 첫 실행·고정 코드 배포·실제 화면·등록된 스케줄·만료/실패 복구를 확인해야 전체 완료를 판정할 수 있다. 현재 배포가 성공했다고 주장하지 않는다.

## 운영 중단과 남은 보안 조치

로컬 `ai-automation.json`의 enabled를 false로 바꾸면 다음 점검부터 수집·유료 호출·공개 전달을 중단한다. 이미 시도한 당일 작업은 자동 재시작하지 않는다. 공개 카드는 현재 사실·기한 검사에서 제외되며 실패 시 남아 있는 유효 카드 또는 기존 규칙을 사용한다. macOS job 제거와 Pages 작업 브랜치 허용 제거는 승인한 설정 범위에서 수행할 수 있다.

앞서 모의 테스트 실패 출력에 노출된 셸 인증정보는 교체가 필요하다. 해당 로컬 로그 삭제·테스트 가짜 환경·실제 하위 명령 환경 허용목록 적용은 완료했다. 저장소 비밀 패턴 검사에서 검출이 없었다는 결과가 대화 노출을 취소하지 않는다. 관련 외부 서비스에 실제 요청하거나 인증정보를 변경하지 않았다.
