# Claude 품질 보강과 무료 재검증 — 2026-11-05

판정: **요청한 후속 1~3 구현·로컬 검증 완료 / 새 모델 품질 미측정 / 자동 운영 보류 유지**.

사용자가 승인한 조사 출력 단순화, 주제·제목 검사, 저장 응답 재검증만 수행했다. 기존 작업 브랜치를 사용했고 새 네트워크·API 요청은 0회다. 실제 키를 읽지 않았으며 기존 누적 예산 원장과 기록된 입력·응답·검증 파일을 변경하지 않았다.

## 변경 내용

조사 모델은 [research-extraction-v2](../../research-extraction.md)에 따라 후보 참조와 사실·정확한 인용·미확인 사유를 반환한다. source ID·URL·해시·조회 시각·claim ID·봉투·미확인 질문과 충돌 참조는 Python이 채운다. 후보와 문서를 선택하는 참조 ID는 여전히 모델이 입력에서 선택해야 한다.

조립한 결과는 기존 v1 증거 검증기를 그대로 통과해야 한다. 인용 위조·unknown에 임의 값/근거 채우기·잘못된 날짜·서로 다른 supported 값의 충돌을 거절한다. 잘못된 값을 자동 교정하거나 실패 사실을 삭제하지 않는다. 검증 통과는 사람 검토 준비 상태일 뿐 사실·공개 승인이 아니다.

compact JSON으로 직렬화한 응답 스키마는 4,586에서 1,657 UTF-8 bytes로 줄었다. **스키마 크기 변화만 측정한 값**이며 실제 요청 토큰·응답 비용·모델 정확도 개선 수치가 아니다.

주제는 호스트 항목의 `topic_basis`에서 허용 주제·제목 조건·근거 claim을 확인한다. 모델 reason을 증명으로 쓰지 않는다. 가족·주말·무료 수식은 포함 항목 전체에 필요하며, 상대 날짜와 인식하지 못한 자유 제목은 검토 대상으로 남긴다. 근거가 빠진 입력은 유료 전송 전에 중단한다. 실패 fallback도 잘못된 주제 연결을 제거하고 사전의 일반 제목만 사용한다.

## 저장 응답 재검증

[재생 결과](replay-results.json)는 원장의 응답 SHA256과 입력 해시를 확인한 뒤 원래 v1 응답을 그대로 검사했다. 과거 실패를 v2 응답으로 변환하거나 새 성공으로 집계하지 않았다.

| 대상 | 결과 |
|---|---|
| 기존 조사 9건 | 기존 계약 통과 0/9 유지 |
| 기존 일별 주제 3회 | 구조 검사 3/3, 새 의미 검사 통과 0/3 |
| 잘못된 취업 연결 | 날짜별 3·1·1건 거절 |
| 가족·주말·무료 제목 조건 위반 | 날짜별 4·7·4건 발견; 항목·수식별 중복 집계 |
| 상대 날짜 표현 | 앞선 두 날짜에서 추가 검토 |
| 실패 fallback | 날짜별 3카드씩 유지, career 연결 제거 |
| 추가 네트워크·API 호출 | 0회 |

[편집 근거표](topic-basis.json)는 기존 사용자 승인 사실을 바탕으로 Codex가 작성한 **개발 평가용 편집 규칙**이다. 각 claim의 실제 문구를 연결했지만 인용 문자열 일치만으로 분류의 진실이 증명되지는 않는다. 새 편집 규칙의 사람 검토는 대기 중이며, 이 표와 fallback 결과는 공개 승인에 사용하지 않는다. 문화·가족·쇼핑 외 청년 활동은 취업에 강제 연결하지 않고 연령 근거만 남겼다. 실제로 무료인 프로그램도 추가 비용 범위를 명확히 확인하지 못하면 무조건적인 무료 제목 근거는 주지 않았다. 유료 혜택 자체를 배제하지 않았다.

## 검증과 재현

- `python3 -m unittest discover -s tests -v`: 전체 285개 통과. 기존 coverage/diagnostics/public_collectors 계열 ResourceWarning은 남아 있다.
- 실제 CLI 진입점에 가짜 HTTP 전송만 연결하여 v2 응답 → Python 조립 → 원장 정산 → 기존 검증 → 비공개 저장 경로를 실행했다. 실제 API는 호출하지 않았다.
- 기존 주제 출력이 구조 검사만 통과해도 의미 오류로 거절되는 경로, 입력 근거 부재가 전송 전 차단되는 경로를 검증했다.
- 재생 중 파일 쓰기·네트워크 금지 및 입력·응답 변조 시 실패를 시험했다.
- `compileall` 및 `git diff --check` 통과. 별도 formatter/linter 설정이 없어 설치하거나 해당 검사를 통과했다고 주장하지 않았다.
- 원격 저장소가 없어 최신 base 동기화·원격 CI를 수행하지 못했다. 현재 세션에서 검토했으며 독립 리뷰는 없다.

실제 재생은 Git 제외 원본 캐시가 있는 현재 작업 환경에서 [사용법](../../claude-trial.md)의 명령으로 반복할 수 있다. 새 output 경로를 사용한다. 원본 응답이나 원장을 초기화하지 않는다.

## 남은 판단

추출 v2는 로컬 계약·실패 테스트를 통과했지만 실제 모델이 새 형식에서 정확한 사실을 더 잘 반환하는지는 아직 측정하지 않았다. 자유 제목·프로필 조건·새 주제의 모든 의미를 자동 판별하는 기능도 아니다. 새 보류표본과 제한된 유료 재실험이 이후 단계이며 이번 작업에는 포함하지 않았다.

실제 API 누적 값은 이전과 동일하게 18요청, usage 기준 $0.045130, 실패 예약 포함 점유 $0.075974다. 기존 무료 수집기의 비용·robots·허용 출처·요청 예산·캐시·쿨다운 정책, Phase0~4 동결 자료와 공개 데이터는 유지했다. 자동 일일 실행·배포·공개 반영·main 병합은 하지 않았다.
