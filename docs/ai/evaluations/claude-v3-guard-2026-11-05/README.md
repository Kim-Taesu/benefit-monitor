# 추출 v3 필드·조건 누락 차단 — 2026-11-05

판정: **필드 표준화·누락 검사 구현 및 로컬 검증 완료 / 새 API 호출0회 / 자동 운영 보류 유지**.

사용자가 지시한 후속 보강을 기존 브랜치에서 수행했다. 실제 키를 읽거나 네트워크를 호출하지 않았다. 기존 무료 수집 정책·누적 $5 원장·v1/v2 실험 기록을 보존했다.

## 변경된 동작

후속 Claude 조사 요청은 [v3 계약](../../research-extraction.md)을 사용한다. 자격·이용기간·접수기간·비용·결제·선정·정원·신청·취소·제한·잔여석12개 필수 항목을 확인하며, 미확인은 null/unknown과 사유로 남긴다. summary/conditions/districts는 선택 항목이다. 임의 한국어 필드명을 자동으로 바꾸지 않고 거절한다. 중복 필드와 후보 전체 누락도 차단한다.

eligibility는 scope/required/not_confirmed로 구조화했다. 이용기간은 날짜, 접수기간은 timezone이 있는 timestamp로 검사하고 기존 valid_from/valid_until/deadline_at에 전달한다. 정원과 잔여석은 분리하며 현재 계약으로 잔여석을 확인했다고 쓰지 못한다. 기존 원문 해시·인용·unknown·충돌 검증도 그대로 유지한다.

같은 후보의 모든 제공 문서에서 대상 제한 후보 문구를 찾아, 해당 문서의 인용과 추출 값 모두에 보존됐는지 검사한다. 요약은 제한없음인데 상세에 유아동반 가족 같은 문구가 있으면 unrestricted 단정을 거절한다. 인용에만 넣거나 not_confirmed로 옮겨 확인된 제한을 숨기는 경우도 차단한다. 불확실한 결과를 자동 수정하거나 공개 승인하지 않는다.

## 검증

- 전체 `python3 -m unittest discover -s tests -v`: **302개 통과**.
- 정상 보존, 제한없음 오판, 인용에만 제한을 넣는 경우, 다른 문서 인용, 나이·성인 제한, 미확인 자격, 필수 필드·후보 누락, 중복, 잘못된 날짜·시간대·잔여석을 시험했다.
- 실제 CLI 경로에서 가짜 HTTP 응답만 연결해 v3 요청 전송 형식, Python 조립, 기존 검증, 비공개 저장을 확인했다. v3 요청에 v2 응답이 반환되면 거절한다.
- 과거 v2의 유효한 로컬 계약 테스트와 읽기 전용 재생은 유지했다.
- `compileall`, `git diff --check` 통과. 별도 formatter/linter는 설정돼 있지 않아 설치하지 않았다.
- 기존 테스트의 ResourceWarning은 남아 있다. 원격 미설정으로 CI·최신 base 동기화는 불가했고 독립 리뷰 없이 현재 세션에서 검토했다.

## 한계와 운영 상태

대상 제한 검사는 한정된 문구 사전과 문자열 대조다. 모든 자격·부정·예외·의미상 동등 표현을 판별하지 못하고 무관한 언급을 보수적으로 걸러낼 수도 있다. 미감지 문구가 없다고 제한없음을 증명한 것은 아니다. 모든 필수 항목을 unknown으로 채운 결과도 조건 해결이나 공개 가능한 데이터로 집계하지 않는다. 사람의 의미·사실 검토는 계속 필요하다.

새 v3 모델 품질, 검토 시간, 독립 보류표본 성능은 미측정이다. 이번 작업에서는 유료 재호출·새 원문 크롤링·자동 일일 실행·공개·배포·main 병합을 하지 않았다. 실제 누적은 이전과 동일하게19요청, usage 계산액 $0.046849, 실패 예약 포함 점유 $0.077693다.

[사용법과 재생 명령](../../claude-trial.md)으로 새 output 경로에 재검증할 수 있다. 원래 캐시와 원장을 초기화하지 않는다.
