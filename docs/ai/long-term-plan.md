# 장기 운영·품질 개선 계획 — 2026-11-05

기존 [로드맵](roadmap.md)의 Phase 0~6은 AI 도입 실험 단계다. 이 문서의 Phase 0~5는 그 뒤의 장기 운영, 유지보수, 결과 품질 개선 단계다. 번호가 겹치므로 이 문서에서는 "운영 Phase"라고 부른다.

| 운영 Phase | 목표 | 비용 | 상태 |
|---|---|---|---|
| 0 | 정리와 측정 기준 | 무과금 | 완료 |
| 1 | 출력 형식 안정화 | 남은 요청 최대 5회 | 거절 2회 뒤 단일 모양으로 교체, 문법 시험 대기 |
| 2 | 사람 검토 흐름 | 무과금 | 도구 완료, 운영 목표 측정 대기 |

| 5 | 장기 운영과 공개 베타 | 유료, 별도 승인 | 시작 전 |

## 운영 Phase 0 — 완료

- 바깥 폴더 AGENTS.md에 실제 저장소 위치와 현재 예외를 적었다. 바깥 폴더는 Git 저장소가 아니라 그 변경은 이 저장소 이력에 없다.
- [기준선](evaluations/baseline-2026-11-05/README.md)에 실패 26건 분류, 평가셋 잠금, 측정 전 목표치를 기록했다.
- 남은 일: 보류용 원문 8건의 정답 라벨은 사람이 작성해야 한다. 서울시 뉴스와 유통 원문을 보류용에 추가해야 한다.

## 운영 Phase 1 — 코드 완료, 실측 대기

- [구조화 출력 전송 계약](structured-output.md)과 전용 프롬프트를 적용했다.
- 2026-11-05 무료 사전검증: 요청 모양이 공급자에게 받아들여졌고, 같은 원문 기준 조사 입력 토큰 −21%, 주제 −11%를 확인했다. 실제 요청마다 같은 무료 검증을 먼저 거친다.
- 같은 날 주제 입력 파일이 73KB라 파일 검사 한도 64KB에 걸려 주제 단계가 요청 없이 멈춘 것을 찾았다. 전송 본문 한도 64KB는 유지하고 입력 파일 한도만 256KB로 분리했다.
- 남은 일: 11/6 이후 클라우드 실행 최대 5회로 형식 거절 0건과 실제 `usage` 입력 토큰을 확인한다.
- 2026-11-06 첫 실제 요청이 문법 크기 초과(HTTP 400)로 거절되어 원장이 중단됐다. 요금은 없고 요청 수 1회와 예약액 $0.013이 원장에 남았다. 유니온·정규식을 뺀 스키마도 같은 날 재시도에서 거절되어, 사실을 한 모양 배열로 바꾸고 유료 문법 시험(1건 $0.001 미만)을 추가했다. 자세한 내용은 [구조화 출력](structured-output.md).
- 같은 날 예약 실행 분석: AI 15분 예약은 약 38번 중 1번만 실행됐고, 공개 브리핑 01:00 예약은 매일 5.8~10.7시간 늦거나(11/4) 빠졌다. 운영 Phase 4 항목으로 승인받아 트리거를 바꿨다([자동화](automation.md)).
