# AI 발견·조사 도입 로드맵

## Phase0~4 최종 결과

사용자 응답 “최종 검토표 확인. 이슈 없음.”을 동결 검토표 전체의 확인으로 반영했다. [사람 검토 원문·정규화](evaluations/phase234-2026-11-05/human-final-review-result.json)와 [최종 판정](evaluations/phase234-2026-11-05/final-evaluation.json)이 현재 정본이다. 기존 프로필·후보·질문 답변 원본의 빈 사람 점수는 검토 전 동결 자료로 보존했다.

회차2 robots 간격 위반과 이전 질문 묶음 미달은 소급 통과하지 않는다. 완결 범위는 사용자 표의 Phase0~4 초기 개발시험이다. 온라인 동일 예산 우위·검토 시간·유료 모델 성능·모든 기관 접근 성공은 별도이며 당시 API과금·공개베타·main병합은 승인되지 않았다. 이후 승인된 Claude 일회 실험은 Phase5이며 공개베타·main병합은 여전히 미승인이다.

## 후속 조사를 재개할 때

1. [Phase0/1 상태](phase01/status.md)를 읽는다. 실패를 완료로 바꾸지 않는다.
2. `python3 -m benefit_monitor.research_probe`로 허용 환경의 실제 연결을 확인한다. cooldown 동안 재시도 금지.
3. [출처 지도](phase01/source-map.md)의 미확인 공식 링크를 채우고 기존 source allowlist와 비교한다. 신규 도메인은 운영 주체·접근 정책 검토 후 별도 변경한다.
4. [비교 계획](phase01/benchmark-plan.md)에 따라 표본 URL과 해시를 잠그고 개발·보류를 분리한다.
5. [실제 캐시 시험](evaluations/2026-11-04-real-cache.md)은 개발 참고이며 신규 탐색·유료 모델 우위 증거로 재사용하지 않는다.

현 작업 저장소는 기존 프로젝트 내부 `.maintenance/p0-source`, 브랜치는 `docs/ai-research-playbook`, 검토 대상 PR17이다. main 병합은 별도 명시적 승인 전 실행하지 않는다.

## Phase5 소액 실험

[2026-11-05 Claude 결과](evaluations/claude-pilot-2026-11-05/README.md): 인증·생성·누적 $5 원장은 동작했다. 개발 원문 조사 계약 0/9, 날짜별 카드 구조 3/3 통과이나 의미 검토 실패로 추가 과금과 운영은 보류했다. 독립 보류표본 비교를 완료한 것으로 간주하지 않는다.

후속 1~3 품질 보강은 완료했다. [축소 추출 계약·주제 의미 검사·무료 재생 결과](evaluations/claude-quality-2026-11-05/README.md). 새로운 유료 응답이나 보류표본 비교가 없으므로 Phase5 품질 판정은 미통과를 유지한다.

추출v2 소수 실제 재실험은 첫 사례에서 형식 통과·중요 자격 누락을 확인해 사전등록에 따라 중단했다. [실제 결과](evaluations/claude-v2-trial-2026-11-05/README.md). API누적19요청이며 자동 운영·공개는 계속 보류한다.

필드명 표준화·자격/기간 구조화·제한 문구 누락 검사는 v3 로컬 보강으로 구현했다. [실제 실패 재생 결과](evaluations/claude-v3-guard-2026-11-05/README.md). 이후 [실제 v3 시험](evaluations/goal-integration-2026-11-05/README.md)을 수행했다. 현재 검사 기준 조사0/5·주제1/2 통과이며 자동 사실 승인 품질은 입증하지 못했다.

## 전체 목표 연결 작업

[수집·AI 검토·주제·일일 연결](automation.md)을 진행 중이다. 실제v3·새 원문 통합 시험, 수집/변경→비공개 검토대기, 승인 사실→주제초안→화면, 일일 명령과 비활성 스케줄 계획을 구현했다. 고정 snapshot·코드 SHA를 사용하는 원격 전달도 구현했다. Python·화면 검증 후 구체적 활성화 검토안을 준비하며, 실제 스케줄·공개 승인과 활성화가 남아 있어 전체 목표를 완료로 보지 않는다.
